# Aitole

Приём оплаты Kaspi Pay по API для бизнеса в Казахстане: QR, счёт на номер клиента, постоянные ссылки на оплату, регулярные счета, возвраты и вебхуки с подписью. Работает поверх вашей кассы Kaspi Pay, деньги идут напрямую вам.

- **Сайт:** [aitole.kz](https://aitole.kz/)
- **Справочник API:** [aitole.kz/docs](https://aitole.kz/docs/) · [markdown для ИИ](https://aitole.kz/docs/index.md)
- **Примеры кода:** [aitole-examples](https://github.com/aitole-kz/aitole-examples) — Node.js, Python, PHP, curl
- **Как узнать, что клиент оплатил Kaspi:** [уведомления и вебхуки](https://aitole.kz/kaspi-uvedomlenie-ob-oplate/)

Песочница доступна сразу после регистрации, без подключения Kaspi. 20 оплаченных платежей в месяц бесплатно навсегда.

Aitole — независимый сервис, не банк и не партнёр АО «Kaspi Bank».

---

**Aitole** is a REST API for accepting Kaspi Pay payments in Kazakhstan: QR codes, phone-number invoices, payment links, recurring invoices, refunds and signed webhooks. [Docs](https://aitole.kz/docs/index.md) · [Examples](https://github.com/aitole-kz/aitole-examples) · hello@aitole.kz
